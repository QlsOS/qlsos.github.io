Редактор цифр сайта

Этот файл лежит в local/, который не попадает в git (см. .gitignore). Он меняет файлы в data/, сайт сам подхватывает цифры.

Папка сайта — та, где лежит index.html. Нужен Chrome, Edge или другой браузер с File System Access API; иначе файлы скачаются, и их надо положить в data/ самому.

Задачи

Блоки A–F, прогресс-бары, лента «Недавно закрыто» и дорожная карта считаются сами из этих двух чисел.

Цифры проекта

Потолок ядра в байтах, число тестов и строк кода. Скрипт tools/gen_metrics.py тоже пишет сюда, а здесь можно поправить руками.
